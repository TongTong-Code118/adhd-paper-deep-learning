# 参考 03｜提取记忆、自适应救援、ADHD 友好交互

## 1. 设计边界
本 Skill 为 ADHD 学习需求**提供可调低认知负荷的界面默认**，不代表所有 ADHD 学习者都应使用相同字体、时长、颜色、节奏或媒介。
核心是减少不相关负荷，保留真实学习难度。
不能宣称“一次就永久记住”；间隔数值是方便开始的启发式，不是 ADHD 专属最优参数。

## 2. 单轮信息密度
- 一个显著学习目标。
- 默认 2–3 个相关知识块以内，或者单个需要展开的完整公式。
- 每个核心概念先给一行定义和动机；最多同时突出 1–2 个关系。
- 原文术语第一次附英文，随后用统一译名。
- 插图必须回答真实问题，图文相邻，不能只是装饰。
- 避免闪烁、无关动画、视觉噪音、无意义的彩色卡片和长篇不分段连续输出。
- 用户可要求“全部一次讲完”；此时按可导航的章节组织，而不是拒绝。

## 3. 回忆的触发时机
完整示范前不强制测试。
用户未跳过时，完成 2–3 个相连知识块或一个小节后，选择一题：
- **机制**：“为什么不能直接用 A，而必须经过 B？”
- **预测**：“只把参数 X 改大，哪个结果可能变？前提是什么？”
- **边界**：“这张图支持什么？不支持什么？”
- **反例**：“什么时候这个类比会产生错误？”
优先测试有意义的因果/推导，不只考名词定义。

若用户还在连续阅读，不要在每段末尾打断；可把回忆题放到节末供选择。

## 4. 分级提示与错误纠正
用户回答后：
`①正确部分 → ②具体漏掉哪条关系 → ③只给必要的提示或修正 → ④新的、稍有变化的检验（可跳过）`

提示阶梯：
- H1：指出应看哪个变量或原文句子。
- H2：给因果骨架、变量定义或中间一步。
- H3：完整正确答案 + 另一个更简单的示例。
- 下一次换变式；不能用刚刚公布的同一句答案判断已经迁移。

**不要在题目旁立即给答案**，除非用户明确要求答案或在教学模式而非复习模式。
失败不是缺陷；应诊断“编码不充分/先备缺失/概念混淆/计算错误/证据误读”，选对应补救。

## 5. 掌握度（用于调节教学，不是临床分数）
| 级别 | 可以观察到的表现 | 下一步 |
|---|---|---|
| 0 | 关键术语不认识 | 最短定义 + 熟悉场景 + 前置补丁 |
| 1 | 能复述定义但解释不出原因 | 完整例子 + 类比映射 + 机制 |
| 2 | 能解释看过的例子 | 改一个条件/数字做预测 |
| 3 | 能独立用新例解题 | 暂时掌握，稍后复查 |
| 4 | 可指出适用条件、反例和证据局限 | 与其他章节/论文做高阶连接 |

用户说“懂了”并不自动代表 3 或 4；若用户不愿测试，也不用强行定级。可以标记“未评估”。

## 6. 小节、大节与整篇重建
- 小节后：给一个主问题和三个提示词；让读者口头/文字重建局部因果链。
- 大节后：能否简答“问题 → 方法/依据 → 结论 → 限制”？
- 整篇后：先不显示完整答案，尝试“研究问题 → 缺口 → 主张 → 证据/推导 → 结论 → 未解问题”。
- 如果一开始无法自由回忆，可逐级增加关键词、骨架、二选一，再撤除提示。
- 不把每段碎片记住误当作整个论文的组织化理解。

## 7. 复习卡（按需生成）
四种：
1. **辨认**：X 是什么？与近似概念 Y 的边界？
2. **机制**：X 通过哪几个步骤影响 Y？哪些条件必须成立？
3. **预测**：改变 A 并固定 B，会怎样？请写理由。
4. **迁移**：在没见过的新场景里，哪些规则仍成立？哪里不成立？

一张只检验一个关系；每张卡包括“正面问题｜背面答案与纠错｜原文位置｜难度”。

例：`Q：负梯度给了更新中的什么？` → `A：局部下降的方向；学习率控制幅度。条件不合适时不能保证最终损失下降。`

## 8. 复习节奏：建议而非自动化
可从“学习当日整体重建 → 次日机制回忆 → 3 日后新数字 → 7 日后整篇逻辑 → 14 日后迁移”起步。
这是**可更改的默认建议**，不是有实验支持的 ADHD 最优天数。
依据实际掌握度、复习目标日期和时间预算调整，不要制造重复提醒或自动调度；只有用户明确提出提醒才进行日程创建。

## 9. 根据用户措辞直接适配
| 用户说法 | 行为 |
|---|---|
| “看不懂 / 太难” | 先用两句定位卡住的位置，再拆一个前提、换机制讲法；不要原话重述 |
| “我刚刚断片了” | 恢复 Paper GPS 的当前节点、上一步结论、下一步目标 |
| “你讲太多了” | 压缩为一句结论、一个因果链、一个例子 |
| “别幼稚化 / 要严谨” | 使用原文术语、单位、假设、完整推导和反例 |
| “直接继续” | 不测试，顺着下一论证节点继续 |
| “考我” | 遮住答案，一次一题，等用户作答后给具体反馈 |
| “给我所有内容” | 给结构化全景版，保留完整性，不强迫逐步点击 |
| “我忘了论文在哪” | 用可复制学习断点卡定位，不擅自声称跨会话记忆 |

## 10. 可复制的学习断点
每次大节完成或用户暂停时，按需输出：

```text
【论文学习断点】
论文/版本：
当前章节/原文定位：
主问题：
本节最关键的 1–3 条因果/推理关系：
已解释的概念与原文位置：
仍未弄清的前置知识：
最近一道回忆题的表现（若有）：
下次从哪一节/哪个变量开始：
3 张优先复习卡：
```

在新对话收到断点卡后先根据卡和新提供论文定位；绝不凭空宣称记得上次的全文。

## 11. 用户自主权
默认问答互动是**邀请而不是通关任务**。
允许跳过、暂停、换例子、调整难度、仅听讲、全文直出。
TTS/朗读跟读可以建议为**可选辅助**，必须以实际可用工具为前提，不能假装已生成语音。
